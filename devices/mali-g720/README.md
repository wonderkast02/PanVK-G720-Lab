# Mali-G720 device registry

This tree stores hardware/kernel identity and evidence links for every tested Mali-G720 target.

Rules:
- never infer ABI compatibility from the GPU marketing name alone;
- record GPU core configuration, GPU ID, kernel driver, UK interface, CSF/firmware data and OS;
- external devices must remain separate until their identity is measured;
- link claims to dumps, logs, tests or investigation IDs.
