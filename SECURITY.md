# Security

Do not post credentials, tokens, private keys, account data or private device
dumps in public issues.

For a security-sensitive report, prefer GitHub's private vulnerability
reporting / Security Advisory flow when it is available for this repository.
If private reporting is unavailable, open only a minimal public issue asking
for a private contact path; do not include the secret itself.

If a credential is ever committed, removing it from the latest tree is not
sufficient: rotate the credential and remove it from the history that will be
published.
