# Claims policy

Claims must be no broader than the evidence.

Acceptable examples include:

- validated on the named reference hardware;
- reproduced N times;
- pipeline creation / submit / fence / readback passed;
- framebuffer matched the expected result;
- a feature was closed in the explicitly qualified scope;
- transport was unavailable when evidence proves the block occurred before the driver.

Do not claim without additional proof:

- Vulkan conformance;
- universal Mali-G720 support;
- universal Winlator/game compatibility;
- a clean kernel when kernel logs were unavailable;
- a GPU crash based only on host termination/assertion;
- full feature implementation based only on feature exposure.

A single Mali-G720 MC8 result is not evidence for every G720 configuration.
