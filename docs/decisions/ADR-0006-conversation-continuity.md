# ADR-0006 — Dev → Dev 2 → current conversation continuity

Status: Accepted

The project history spans the Dev, Dev 2 and current development conversations.

Conversation text is context, not authoritative technical evidence. The long-term record is the normalized Lab investigation plus preserved raw reports, hashes, source identity and test outputs.

Therefore:
1. historical conclusions are imported with their original evidence and status;
2. failed and discarded hypotheses remain recorded;
3. later evidence may supersede a conclusion without deleting the earlier record;
4. code changes remain in the main PanVK repository;
5. the Lab links investigations to main-repo Issues, PRs and commits.
